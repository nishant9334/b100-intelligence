07 · Architecture

From raw SQL to production insight

Extract & clean
Parse the SQL dump, standardise year labels, fix nulls, classify sectors, compute D/E, margins, FCF and coverage.
Warehouse
Star schema in PostgreSQL: dim_company, dim_year, dim_sector and fact tables, loaded with idempotent upserts.
Serve
Seven Power BI dashboards, a Django REST API with Swagger docs, and Celery jobs that rescore daily.
